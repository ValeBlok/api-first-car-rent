# API для бронирования автомобилей

## Описание

Сервис для бронирования автомобилей. Была разработана спецификация и код к ней.

### Endpoints

- **Регистрация** — создается новыый пользователь
- **Бронирование автомобиля** — возможность забронировать автомобиль
- **Отмена бронирования** — отказ от бронирования
- **Просмотр штрафов** — возможность просмотреть штрафы пользователя

## Swagger

Просмотр swagger возможен по адресу http://127.0.0.1:8000/docs.

## Метрики и логи

Prometheus-метрики доступны по адресу http://127.0.0.1:8000/metrics.

Сервис экспортирует:

- `car_rent_http_requests_total` — количество HTTP-запросов по методу, пути и статусу ответа
- `car_rent_http_request_duration_seconds` — длительность HTTP-запросов по методу и пути
- `car_rent_http_requests_in_progress` — количество запросов, которые сейчас обрабатываются
- `car_rent_users_total` — количество зарегистрированных пользователей
- `car_rent_bookings_total` — количество активных бронирований
- `car_rent_fines_total` — количество созданных штрафов

Дашборды Grafana доступны по адресу: http://127.0.0.1:3000.

Prometheus доступен по адресу: http://127.0.0.1:9090.

Loki для логов доступен по адресу: http://127.0.0.1:3100.

## Запуск

Понадобится docker.

```bash
docker compose up -d
```
